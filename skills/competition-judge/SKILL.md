# 比赛定级

## 何时使用
用户给的是一个比赛（或证书）名称，想知道"算几级、加多少分"。若用户给出完整成果清单要算总分，转 `score-calc`（本技能是其第一步）。

## 四步判定（不得跳步）

### ① 认赛事
在《赛事定级表（214 条）》里按**最长别名**匹配：
- "大广赛" → 全国大学生广告艺术大赛
- "数模" → 全国大学生数学建模竞赛
- "互联网+" → 中国国际大学生创新大赛
- "挑战杯创业" 优先于 "挑战杯"

找不到就只问一句全称，不要拿相近赛事凑。

### ② 认级别（证据优先级从高到低）
1. 描述中的显式级别词：国家级/国赛/国二、省级/省赛/省二、校级/校赛、院级/院赛；
2. 主办单位或证书落款（颁奖）单位；
3. 赛事库里的"级别提示"（此时置信度只能标"中"）。
**赛事名称含"全国/中国/中华"不构成国家级证据。**

### ③ 认奖项
- 名次优先：冠军/第 1 名 → 第 1 档；第 2–3 名 → 第 2 档；第 4–6 名 → 第 3 档；第 7 名以后 → 第 4 档。
- 等级词：特等奖 > 一等奖/金奖 > 二等奖/银奖 > 三等奖/铜奖 > 优秀奖。
- 不分等级 → 按三等奖（附表说明 5）。
- 学术科研（大创等）写"结项/立项"的，按申报排序取档：第一负责人 / 第二 / 第三以后。
- 美赛：O、F = 一档；M = 二档；H = 三档；S（成功参赛）= 不加分。

### ④ 取分与折算
- 按《附件2》对应指标与级别取分（B1 学术竞赛 10/8/6/5；B2 技能竞赛 20/15/12/10 等，以表为准）。
- 集体折算：5 人以内各成员减半；5 人以上仅主要负责人减半、其他不加；文艺与体育一律减半。
- 统数学生追加院内口径：不在《推免奖励分细则》名单内的，国家级按校级、省级按院级；美赛 S 奖与星级志愿者不加分。

## 输出格式

```
【赛事】全称（命中别名）
【级别】XX（依据：…）· 置信度 高/中/低
【奖项】XX → 第 N 档
【加分】X 分（集体折算后 X 分）
【依据】附件2 B? 子类：分档…
```

## 拒绝给分的情形
- 无级别词、无主办单位、赛事库也无级别提示；
- 赛事未收录且无法判断级别（如"某企业杯 一等奖"）；
- 分值表没有对应的"子类 + 级别"组合。

此时只输出：`暂不给分。请补充：证书落款（颁奖）单位 / 获奖等级 / 团队人数与本人角色。`

## 边界
- 不认定"这个奖学校认不认"，只按文件口径折算。
- 同一成果不重复计分；已用于其他分项的成果要提示冲突。
