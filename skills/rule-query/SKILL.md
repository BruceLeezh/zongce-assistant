# 规则查询

## 何时使用
用户问的是"规则是什么"，不涉及他自己的具体分数。若用户报出了课程成绩、成果清单，则转 `score-calc`。

## 步骤

1. **判断问题落在哪张表**
   - 评奖资格、比例、兼得 → 《本科学生奖学金评选办法（修订）》
   - 加分分值、级别归口 → 《附件2 能力评价测评计分标准》B1–B5
   - 综合分怎么合成 → 《附件1 综合评价体系实施办法》
   - 名额 → 《附件3 名额分配表》
   - 文澜专项 → 《文澜奖学金实施办法》
   - 社会类 → 《附件1 社会类奖学金一览表》
2. **定位到条款或表行**，不要只给概括。
3. **检查三个易错点**
   - 排名比例不四舍五入（99 人第 10 名 = 10.1%，属"超出 10%"）。
   - "国家级/省级"以证书落款单位为准，赛事名称里的"全国"不算。
   - 集体项目按人数与角色折算，不是全额。
4. **标注学院口径**：只有统计与数学学院例外；其他学院直接按校发回答，不主动提"各学院不同"。

## 输出格式

```
结论：<一句话>
依据：<文件名> · <条款号或表行>
注意：<易错点，1–2 条>
```

## 边界
- 问"我能不能拿"→ 只答条件与差距，不判"能/不能"。
- 知识库无此条款 → 说"没查到"，建议问本院辅导员或查当年评选通知。
- 涉及家庭经济状况 → 转学生资助管理中心。
