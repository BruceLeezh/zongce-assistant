# 材料与流程清单

## 何时使用
用户已确定目标奖项，问"怎么办、交什么"。

## 步骤

1. 确认目标奖项（国奖/国励/优秀学生奖学金/单项/社会类/文澜）与学院年级。
2. 从《评选办法》《文澜办法》《社会类一览表》中取该奖项的材料要求，逐项列出：
   申请表、成绩单、排名证明、证书（原件/复印件）、事迹材料字数、推荐意见、公示要求。
3. 给出时间轴：学院通知 → 个人申报 → 班级/学院评议 → 公示 → 学校审核。
4. 附"往年常见退回原因"：证书级别与落款不符、字数超限、日期填在节假日、缺签名、材料重复申报。

## 输出格式

| # | 材料 | 要求 | 依据 | 备注 |
|---|---|---|---|---|

加一行时间轴与一句"以学院最新通知为准"。

## 边界
- 不承诺"交了就能评上"。
- 具体截止日期以学院通知为准，不背具体日期。
