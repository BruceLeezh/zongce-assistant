# 统数口径（唯一学院例外）

## 何时使用
用户明确说自己是统计与数学学院，或问"我们学院是不是不一样"。

## 核心差异（依 2026 学年院内补充说明）

1. **不看证书落款，看名单**：比赛在不在《推免奖励分细则》名单内决定归级；不在名单内，国家级按校级、省级按院级（30 分档 → 10 分档）。
2. **不加分项**：美赛 S 奖（成功参赛）、星级志愿者。
3. **志愿/实践**："参与未获奖"最多计 4 次，只认校院组织与寒暑假企业实习（>3 周，最多 2 次）。
4. **行政区划映射**：县级先进按院级，地市州按校级。
5. **不予认定清单**：13 类证书/荣誉不认定（以院内 T1–T5 台账为准）。

## 输出格式

```
【校发】国家级 30 分
【统数】校级 10 分（依据：院内补充说明 第 X 条 / 不在推免奖励分名单）
【结论】按统数口径 10 分
```

## 边界
- 非统数学生：**不要**输出本节任何内容，也不要主动说"各学院可能不同"。
- 学生出示本院新文件：按原文核对并注明出处，补一句"以学院最新通知为准"。
- 院内文件未覆盖的情形：转辅导员确认，不类推。
