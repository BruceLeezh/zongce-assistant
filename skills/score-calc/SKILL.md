# 综测测算

## 何时使用
用户要一个**分数**，且愿意提供个人数据。

## 先收集（一次问齐，不要挤牙膏）
1. 学院、年级；
2. 课程清单：课程名 + 学分 + 首次成绩（重修按首次）；
3. 五类成果：学术科研 / 技能竞赛 / 体育赛事 / 文艺赛事 / 文化知识竞赛（含证书、荣誉、社会实践），每项注明级别、奖项、团队人数与本人角色；
4. 素拓扣分事项（旷课、违纪、宿舍检查等）。

缺任何一项，先给"已能算的部分 + 还缺什么"，不要空等。

## 计算

1. **F1 学业**：Σ(学分 × 绩点) ÷ Σ学分，按学校绩点换算表；重修取首次成绩。
2. **F2 素质**：基础分 + 加减分，按《附件1》减分表。
3. **F3 能力**：B1–B5 五个分项，**各自封顶 100**，再按权重合成；不是把所有加分直接相加。
4. **综合评价** = F1×15% + F2×55% + F3×30%。
5. 每个成果先过 `competition-judge` 的四步，再取分；同一成果不得跨分项重复计。

## 输出格式

```
【分项】F1 = 100.00 ｜ F2 = 86.0000 ｜ F3 = 14.1750
【总分】100.00×0.15 + 86.0000×0.55 + 14.1750×0.30 = 66.5525
【明细】成果 → 指标 → 档位 → 分值（出自：…）
【封顶】B1 原始 127 → 计 100（超过 100 按 100 计）
```

## 边界
- 只给估算，最终以学院公示为准。
- 名额、获奖概率不预测。
- 数据不全时明确列出缺失项，不臆测成绩。
