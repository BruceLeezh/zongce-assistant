# 系统填报与审批表

## 何时使用
用户已在办具体手续，卡在系统操作或表格填写。

## 步骤

1. **给入口路径**
   - PC：`https://istu.zuel.edu.cn` → 统一身份认证 → 学生奖助 → 综合测评（Chrome/Edge 最新版）
   - 移动：企业微信 → 工作台 → 智慧学工 → 学生奖助 → 综合测评
2. **先排一个高频坑**：进页面取消勾选「仅看待我评分的项目」，否则指标看不全。
3. **逐栏讲写法**（依《附件7 填写说明（2026版）》）：
   - 排名比例不四舍五入；
   - 申请理由不得用"我"开头、不得口语化、有字数上下限；
   - 推荐理由必须辅导员本人写，不得代写、不得雷同；
   - 填表日期不得落在节假日；
   - 必修课门数与及格门数要与成绩单一致。
4. **强调两条硬边界**
   - **保存 ≠ 提交**，状态必须显示"已提交"；
   - 未审核可自行撤回，已进入审核只能联系辅导员退回。
5. **报障材料**：学号、发生时间、设备与浏览器、报错截图、操作步骤。

## 边界
- 不代填、不代写推荐意见。
- 系统页面改版时以实际页面为准，不硬背菜单。
