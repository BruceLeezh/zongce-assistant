# 差距诊断

## 何时使用
用户已有（或可算出）综测分，关心"够不够、差多少"。

## 步骤

1. **先过资格闸门**（任一不满足，直接说明，不再算分差）
   - 年级、学籍状态、有无违纪/挂科；
   - 排名比例（不四舍五入）；
   - 社会类奖学金：学院与年级是否在覆盖范围（海特 3 院、华为 6 院 2023 级、九州通 4 院、比亚迪 15 院、紫光全校但须家庭经济困难认定）。
2. **算分数差**：目标奖项的参考线（往年公示分/名额比例）− 当前分。
3. **给可补项清单**：按"每投入 1 分力气能加多少分"排序，标注截止时间与材料要求。
4. **区分两类差距**：条件差（不可通过加分弥补，如比例超限）与分数差（可通过成果弥补）。

## 输出格式

```
【资格】满足 / 不满足（原因）
【分数】当前 72.4 ｜ 参考线 78.0 ｜ 差 5.6 分
【可补项】① …（+3 分，需 X 材料，截止 Y）② …（+2 分）
【提醒】排名比例不四舍五入；最终以学院公示为准
```

## 边界
- 不预测获奖概率，不说"你稳了/没戏"。
- 参考线来源不明时标注"往年参考，非本年线"。
- 不提供"怎么把分做高"的擦边建议。
