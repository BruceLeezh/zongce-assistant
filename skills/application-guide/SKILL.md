# 奖学金志愿填报

## 何时使用
综测出分之后，进入奖学金申请阶段。

## 关键事实（依《奖学金操作手册（学生端）》）

1. 奖学金是**志愿填报制**，不是"符合条件自动获得"。
2. 系统自动判定资格，学生只填志愿。
3. **综合类奖学金只能拿一个**；综合类与单项奖学金不可兼得；各单项之间可兼得。
4. 志愿顺序决定去向，**第一志愿最关键**。
5. "是否服从调剂"为必填项；不服从可能落空。
6. **提交后不可撤回**（与综测填报不同），提交前必须逐项核对。

## 七步流程

1. 确认综测状态为"已提交/已审核"；
2. 进入奖学金申请入口，核对系统判定的资格；
3. 查看可填志愿与名额；
4. 按"最想去 > 较稳 > 保底"排序；
5. 选择是否服从调剂；
6. 逐项核对后提交（提交前截图留存）；
7. 在"我的申请"查审核进度，被退回按要求补正。

## 输出格式

```
【资格】系统判定：…
【志愿建议】1) … 2) … 3) …（理由：名额/竞争/兼得限制）
【必填】是否服从调剂：…
【提醒】提交后不可撤回，提交前核对 X/Y/Z
```

## 边界
- 不替用户决定志愿顺序，只给判断依据。
- 名额与竞争度以当年公示为准，不预测录取概率。
