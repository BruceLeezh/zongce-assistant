# 综测小助

中南财经政法大学本科生**综合测评与奖学金事务**数字员工。WPS Comate 技能开发大赛（中级赛道·数字员工/专家）参赛作品。

## 解决什么问题

综测与评奖季，学生要同时处理四件事：算分、判级别、对材料、填系统。每一件都有细节坑：

- 某项成果**到底算不算**、算哪一档、加几分 —— 规则散在多个校发附件里，还分学院口径
- 离目标奖学金**还差多少分**、补哪一项最划算 —— 需要把规则倒推成可计算的差距
- 材料**要交哪些**、什么时间、什么格式 —— 少一件就被退回
- 系统**怎么填**、审批表逐栏写什么 —— 填错要撤回重来

本作品把这些判断固化成 8 个单一职责技能，由数字员工负责路由与追问，技能负责把每类问题按固定步骤做完。

## 结构

```
skills/                      8 个技能，一个技能只做一件事
├── rule-query/              规则查询：某个奖什么条件、某项成果能不能加分
├── competition-judge/       比赛定级：口语描述（"数模省二"）→ 级别/奖项档/加分
├── score-calc/              综测测算：课程 + 五类成果 → F1/F2/F3 → 综合评价总分
├── gap-diagnosis/           差距诊断：离目标奖项差多少分、补哪项最划算
├── material-checklist/      材料与流程：要交什么、什么时间、常被退回的原因
├── form-guide/              系统填报：系统怎么填、审批表逐栏、提交后怎么撤回
├── tsxy-caliber/            统数口径：学院的院内例外（降等、不认定、限次）
└── application-guide/       志愿填报：奖学金申请怎么排志愿、服从调剂、兼得规则

rules/                       规则卡与可执行实现
├── 综测与评奖规则卡.md        519 行，12 章，每条结论标注文件名 + 条款号
├── 测算逻辑与实现口径.md      160 行，把规则倒推成计算口径
└── 综测计算器.py             1055 行，命令行计算器
```

`SKILL-PACKAGE.md` 是技能包原始说明（技能与数字员工的职责边界）。

## 设计取舍

**技能之间不互相调用**，由数字员工路由。任一步出错能定位到具体技能，也便于单独修订 —— 这是刻意放弃"一个大提示词包打天下"的做法。

**规则卡逐条带出处**。综测规则的典型坑是"以哪个版本为准"：同一事项在不同附件里口径不一致时，规则卡显式记录冲突与定案结论，而不是给一个不标来源的数字。

**查不到就转人工**。规则卡覆盖不到的，明确要求转辅导员，不硬答。宁可说"不确定"，也不编一个看起来合理的分数。

## 知识库说明

技能只负责推理与约束，事实来自知识库。运行前需在平台侧准备校发文件（综合评价体系实施办法、能力评价计分标准、奖学金评选办法、名额分配表、系统操作手册等）。

**本仓库不含校发文件原文**，仅包含技能定义、规则卡与计算实现。规则卡引用条款号，原文请以学校官方发布为准。
