# 测算逻辑与实现口径

> 用途：把「综测计算器.py」里的算法翻译成 **Comate 平台可落地的表公式与工作流步骤**。
> Python 只是校验与出标准答案的工具，**平台内不跑 Python**——真正的测算靠这张文档 + 多维表公式。
> 本文与 `综测计算器.py --selftest`（174 项断言）一一对应，任一处口径不一致即为 bug。

## 一、为什么必须分成两张分值表

S3 原文的分值表有**两种形状**，混在一张表里必然算错。

**形状 A —— 按「档位」取分**：先定级别，再按奖项等级/名次/位次取第 n 个数。

| 子类 | 键（级别） | 档位含义 | 分值 |
|---|---|---|---|
| 学术竞赛 | 国家/省/校/院级 | 1一等 2二等 3三等 4优秀奖 | 国 30/25/22/20、省 20/15/12/10、校 10/8/6/5、院 5/3/2/1 |
| 技能竞赛 | 同上 | 同上 | 同上 |
| 文艺赛事 | 同上 | 同上 | 同上 |
| 文化知识竞赛 | 同上 | 同上 | 同上 |
| 体育赛事 | 同上 | **名次 1–8**（不折四档） | 国 30/25/20/15/15/10/10/10、省 20/15/10/8/8/4/4/4、校 10/8/7/6/6/2/2/2、院 7/6/4/3/3/1/1/1 |
| 学术论文 | 一类/二类/三类/四类/一般 | **作者位次** 1独撰 2合著第一 3第二 4第三以后 | 一类 30/20/15/8、二类 20/15/10/5、三类 15/10/5/3、四类 10/5/3/2、一般 5/3/2/1 |
| 学术科研 | 国家/省/校/院级 | **申报排序** 1第一负责人 2第二 3第三以后 | 国 20/15/8、省 15/10/5、校 10/5/3、院 5/3/2 |
| 发明专利 | 国家发明专利/实用新型/外观设计 | 无（单值） | 20 / 4 / 2 |
| 技能证书 | 高级/中级/初级 | 无（单值） | 10 / 5 / 3 |

**形状 B —— 按「级别」取第 n 个**：类别固定，级别是四档里的第几个。

| 子类 | 类别 | 国家级 | 省级 | 校级 | 院级 |
|---|---|---|---|---|---|
| 团学活动 | 优秀学生干部 | 30 | 20 | 10 | 5 |
| 团学活动 | 优秀学生组织主要负责人（5 人以内） | 15 | 10 | 6 | 3 |
| 团学活动 | 团学先进个人 | 20 | 15 | 8 | 4 |
| 志愿服务 | 先进个人 / 优秀团队 | 30 | 20 | 10 | 5 |
| 社会实践 | 先进个人 / 团队 | 30 | 20 | 10 | 5 |
| 社会实践 | 调查报告 | 25 | 15 | 8 | 4 |

**两条最容易翻车的坑**

1. **体育赛事不能折成四档**。校级第 3 名是 **7 分**，不是"三等奖"的 6 分；第 5 名是 6 分，第 6 名也是 6 分——八档不同值，必须按名次查。
2. **优秀奖 ≠ 优胜奖**。优秀奖是第四档（在 30/25/22/20 里取 20）；"优胜奖/不分等级"按附表说明(5) **取三等奖**。混用会差 4 分。

## 二、个人情况表字段

| 字段 | 类型 | 说明 |
|---|---|---|
| 学号 / 姓名 | 文本 | 用于回写与核对，不做排序 |
| 学院 | 单选 | 决定用哪套学院口径（SK6） |
| 年级 | 单选 | 大二及以上才有参评资格 |
| A1–A4 减分 | 数字 | 思想政治/道德品质/组织纪律/身心健康，各扣各的 |
| 课程明细 | 子表 | 课程名、学分、**首次**成绩 |
| 成果明细 | 子表 | 见下 |

成果子表字段：

| 字段 | 何时必填 | 取值 |
|---|---|---|
| 成果名称 | 总是 | 同一项目重复获奖时用来判重 |
| 子类 | 总是 | 学术竞赛 / 学术论文 / 发明专利 / 学术科研 / 技能竞赛 / 技能证书 / 文艺赛事 / 体育赛事 / 文化知识竞赛 / 团学活动 / 志愿服务 / 社会实践 |
| 级别 | 除专利、证书外 | 国家级 / 省级 / 校级 / 院级（论文用一类~一般；专利用类型；证书用认定级别） |
| 类别 | 团学活动 / 志愿服务 / 社会实践必填 | 见形状 B 表 |
| 奖项 | 竞赛、文体、荣誉类 | 原始写法，如"二等奖""第3名""优胜奖" |
| 位次 | 学术论文 / 学术科研 | 独撰、合著第一、第二、第三以后 / 第一负责人、第二、第三以后 |
| 人数 | 集体项目 | 团队总人数；个人项目填 1 |
| 主要负责人 | 集体项目 | 是 / 否 |
| 未获奖参与 | 视情况 | 勾选后走 0.5 分/次逻辑 |

## 三、三个分项与总分

```
F1 基本素质 = Σ(Ai)              Ai = max(0, 25 − 该项减分)   i=1..4
F2 知识水平 = Σ(学分 × 首次成绩) ÷ Σ学分
F3 能力评价 = Σ( min(100, Bk原始) × 权重k )   k=1..5
            权重：B1 .35  B2 .15  B3 .15  B4 .10  B5 .25

综合评价 = F1 × 0.15 + F2 × 0.55 + F3 × 0.30
```

四处常见错误：

- **F1 每项不低于 0**。减满 25 就停在 0，不出现负数。
- **F2 用首次成绩**，不是重修后的分；也不是算术平均，是**学分加权**。
- **封顶在加权之前**。B1 原始 127 → 先压到 100 → 再 ×0.35 = 35。先加权再封顶会算成 44.45。
- **封顶是每个分项各自 100**，不是五项合计 100。

## 四、集体项目折算（附表说明 4）——三句话，三套规则

原文一句话里其实藏了三种处理方式：

| 情形 | 处理 | 对应子类 |
|---|---|---|
| "体育赛事及文艺赛事，**集体或合作项目**……各成员……减半加分" | **集体项目（n≥2）不论人数一律减半；个人项目不减半** | 文艺赛事、体育赛事 |
| "学术科研类项目，结项后主持人参照第一项目负责人，其他成员按申报排序依次对应" | **不减半**，档位本身就是排序 | 学术科研 |
| 位次/作者身份已经写进档位里的 | **不减半** | 学术论文、发明专利、技能证书 |
| 个人荣誉称号，不是集体项目 | **不减半** | 团学活动 |
| 其余（默认句） | 见下 | 学术竞赛、技能竞赛、文化知识竞赛、志愿服务、社会实践 |

默认句的分支：

```
人数 n = 1        → 不减半
n ≤ 5            → 各成员减半
n > 5 且是负责人   → 减半
n > 5 且不是负责人 → 0 分（不是减半，是不加）
```

**决策顺序必须是：先查是否命中"集体项目一律减半 / 不减半"的特例，再落到默认句。** 顺序反了，学术科研主持人会从 15 变成 7.5。

> 注：原文限定词是"**集体或合作项目**"。校运会 400 米、800 米这类**个人项目**没有合作者，不适用减半——这是最容易多扣一半分的点，`_demo1.json` 里个人项目按 7 分（不是 3.5）已作为自检项固定下来。

## 五、去重与参与分

**同项目判重**（附表说明 3）：键 = `指标 + 子类 + 成果名称`，同键取最高分。
- 同一项目校级+省级都获奖 → 取高的那个，不叠加。
- 同一项目在**不同**子类下获奖（如既算竞赛又算科研）→ 可累计。
- 不同项目在同一子类 → 可累计。

**未获奖参与分**：0.5 分/次，**每个指标**累计上限 2 分。
- 竞赛类（学术竞赛、技能竞赛、文艺赛事、体育赛事、文化知识竞赛、学术科研）：必须**经学院及以上选拔推荐**；报名即参赛不给分。
- 志愿服务、社会实践：有参加证明即可；但学院口径另有"最多申报 4 次""荣誉与单次不重复认定"的限制（见规则卡 T9/T10）。

## 六、平台实现（WPS 多维表 / 智能表格）

1. **两张分值表**：按上节「形状 A」「形状 B」各建一张，`分值` 列拆成 4–8 个数字列（档位1…档位8），比存"30/25/22/20"字符串好查。
2. **取值用 VLOOKUP + 档位**：
   - 形状 A：`VLOOKUP(子类&级别, 形状A!键, 档位列索引)`，档位由奖项写法换算（见下）。
   - 形状 B：`VLOOKUP(子类&类别, 形状B!键, 级别序号+1)`。
3. **奖项写法 → 档位**用嵌套 IF 或查找表，顺序要对：
   `第N名` → 1/2/3/4 折档；`优秀` → 4；`优胜`/`入围`/`佳作`/`不分等级` → 3；`特等`/`金`/`冠军`/`一等` → 1；`银`/`亚军`/`二等` → 2；`铜`/`季军`/`三等` → 3；其余 → 3。
   **顺序错了会把"优秀奖"当成优秀 → 4 档没错，但会把"优胜奖"误判成 4 档；"特等奖"三个字里没有"一等"二字，漏写特等规则会整档掉到三等奖。**
4. **集体折算**用 IF 嵌套，按第四节决策顺序写。
5. **去重**用数据透视或数组公式按 `指标+子类+名称` 取 MAX。
6. **封顶与加权**最后一步做，公式顺序：`MIN(100, Bk) * 权重`。
