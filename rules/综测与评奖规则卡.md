## 1. 综合评价怎么算（S2 第八条 / 第十一条 / 第十三条）

```
综合评价 = 基本素质 F1 × 15% + 知识水平 F2 × 55% + 能力评价 F3 × 30%
F1 = A1思想政治 + A2道德品质 + A3组织纪律 + A4身心健康      （各基准 25 分，共 100）
F2 = Σ(课程学分 × 单科成绩) / Σ(课程学分)                    （上学年所修全部课程；单科取首次考试成绩）
F3 = B1科研创新×35% + B2专业技能×15% + B3文体特长×15% + B4社会工作×10% + B5社会实践×25%
```

- **F1 只减不加**（S2 第十条）：4 个分项各以 25 分为基准，按记实减分，每项最多减 25 分。
- **F3 分项各自封顶 100 分**，再加权（S2 第十三条）。
- 适用对象：二年级（含）以上全日制普通本科生（S2 第四条）。**大一新生不参评**。
- 测评每年 9 月开展 1 次（S2 第七条）。

### F1 减分标准（S2 第十条）

| 分项 | 情形 | 减分 |
|---|---|---|
| A1 思想政治 | 无故不参加校/院/年级思政教育活动或党团班级集体政治学习 | −2/次 |
| A2 道德品质 | 不讲社会公德、故意损坏公物或破坏环境 | −4/次 |
| A2 道德品质 | 不负责任、不讲诚信造成负面影响 | −3/次 |
| A2 道德品质 | 寝室卫生检查不合格 | −2/次 |
| A3 组织纪律 | 受校、院通报批评 | −3/次 |
| A3 组织纪律 | 打架斗殴、赌博、酗酒、观看传播反动淫秽制品（未构成处分） | −2/次 |
| A3 组织纪律 | 未经请假晚归 | −4/次 |
| A3 组织纪律 | 未经审批擅自校外租房 | −12 |
| A4 身心健康 | 未请假不参加课外体育锻炼、心理健康教育活动 | −2/次 |

- 违反四项基本原则、参与危害国家尊严/社会秩序活动、受司法处罚 → **F1 记 0 分**。
- **学院可增补减分条件**（S2 第十条第四款）→ 见 §6。
- 体测：A4 要求"体质健康测试成绩合格"；**体测不及格直接取消当年度参评资格**（S1 第十二条）。

### 全表通用规则（S3 附表说明）
1. 每个分项 B1-B5 **各自封顶 100 分**。
2. 同一指标内不同类别加分**累加**。
3. 同一项目同类重复获奖取最高分；**不同类别获奖可累计**；同类别不同项目可累计。
4. 集体/合作项目：除体育、文艺、学术科研外，5 人以内**各成员减半**；5 人以上**仅主要负责人减半**，其他成员不加分。体育、文艺集体项目**各成员减半**。学术科研结项主持人按第一负责人计，其他成员按申报排序对应计分。
5. 不分等级 → 按三等奖；按名次 → 第 1 名=一等、第 2-3 名=二等、第 4-6 名=三等、第 7 名及以后=优秀奖；金银铜/冠亚季军 → 一二三等。
6. 奖项、荣誉称号、技能证书等级由**学校本科学生奖学金综合评价领导小组统一核定**，核定认可后方可加分。
7. 等级认定严格按**获奖证书落款单位（颁奖单位）级别**。
8. 加分时间认定以**表彰/证书/奖状标注时间或论文发表时间**为准。

## 3. 参评资格与一票否决（S1 第十一、十二条）

**有下列之一，当年度无参评资格**：
1. 因违反校纪校规受纪律处分**未获解除**；
2. 有不良诚信记录；
3. 上学年**体质健康测试不及格**（<60 分）；
4. 上学年**所修读课程有不及格**；

## 6. 学院口径

**默认口径：全校统一按校发文件（S1–S3 + 本学年评选附件）测算。**
**唯一例外：统计与数学学院有本学年院内补充说明（T1–T5），统数学生必须先切统数口径。**

> 不要再把“各学院细则不同”当成默认前提。除统数外，其余学院没有本学年可加载的院内综测补充说明，一律按校发测算；学生若主动出示本院书面细则，再按细则核对并注明出处。

### 7.2 奖学金申请志愿填报口径（F4b《奖学金操作手册【学生端】》，本学年权威）

> 来源：用户 2026-10-16 提供的 `奖学金操作手册【学生端】.pdf`（10 页，MD5 8c6d772fe…），微信收文 2026-10-04；全文入 `03 知识库\_附2025-2026\附件4b-奖学金操作手册（学生端）.txt`。
> **与 §7.1 的关系**：§7.1 是**综合素质评价填报**（学生奖助 → 综合测评，9 月）；本节是**奖学金申请志愿填报**（学生奖助 → 奖学金，9 月底）。两份是同一系统的两个入口，都要用。两份手册的分工见 `03 知识库\_附2025-2026\_两份操作手册的分工.md`。

**入口**：`https://istu.zuel.edu.cn/xsfw/sys/xggzptapp/*default/index.do` → 统一身份认证 → **【学生奖助】→【奖学金】**（与综合测评是两个不同图标）。移动端：企业微信 → 工作台 → 智慧学工 → 学生奖助 → 奖学金。**两端数据实时同步**。

**核心机制（这是回答"我该怎么报"的依据）**：
1. **志愿填报模式，不用写申请表**：系统按各奖种评选条件**自动判定资格**；学生只做「把符合条件的奖项按意愿排序 → 提交志愿」。卡片上显示 **【添加】/【查看详情】**（符合）或 **【不可申请原因】/【查看详情】**（不符合，点开可见具体未达标条件）。
2. **综合类 vs 单项类**：综合奖学金（国奖、国励、优秀学生奖学金等）**可同时申请多个，但只能获评一个**；单项奖学金（科研创新、文体佳绩、社会工作、社会实践）**符合条件可同时获得多个，不参与志愿排序**。**综合类与单项类不可兼得**；评定时**先评综合类、后评单项类**，获评综合类后不再参与单项评定。

   > 注意：手册在这里只说「不可兼得」，**未说综合类内部五奖互斥**；S1 第二十六条另有明文（国奖/国励/优奖/社会类/文澜互不可兼得）→ **兼得问题以 S1 为准，手册只描述系统操作**。
3. **录取顺序**：综合奖学金**先按综合测评成绩从高到低排序，再按志愿顺序依次录取**；第一志愿名额满则检索第二、第三志愿。→ **综测分数决定排队位置，志愿顺序决定排队时的去向**，两者都要报。
4. **系统推荐志愿排序**（点【推荐志愿排序】一键生成）：**国家奖学金 → 国家励志奖学金 → 社会类奖学金（金额从高到低）→ 校设奖学金（金额从高到低）**；手动调过顺序后再点会弹窗问「是否按照推荐志愿顺序排序」，选【是】覆盖、选【否】保留。
5. **【是否服从调剂】是必填项**：选【是】时，若所有志愿均未录取且综合类奖项仍有剩余名额，系统按综测成绩从高到低把学生调剂过去；选【否】且志愿名额已满 → **本轮综合类无法获评**（单项不受影响）。
6. **建议单项奖全部勾选**（手册原文：「建议单项奖全部勾选」）——单项不参与排序，不勾白不勾。
7. **提交后不可修改、不可撤回**：志愿提交即进入学院审核评审流程。这是与 §7.1 相反的规则（§7.1 的综合测评在班级未审核前可撤回），**产品必须分别作答，不能混用**。

**「我的申请」与国奖特例**：按批次显示已提交奖项卡片（名称、综合/单项、志愿顺序、评定学年与学期、审核进度）。**国家奖学金特别流程**：学院审核通过后，卡片内出现 **【提交申请理由】** 入口，可填申请理由并导出国家奖学金申请表；**校级审核完成后申请理由变只读**。→ 与 §8 的国奖审批表填写口径衔接：申请理由要在学院审核通过后、且按 F7 的 200 字与禁语规则写。

**咨询与反馈（F4b 第六节）**：
- 奖项评选条件、资格判定、志愿填报异常 → **本年级（班级）辅导员**，由学院统一答复；对系统资格判定有异议 → 联系辅导员核实。
- **综合测评成绩与加权平均成绩取自综测系统，一经发布公示后不可修改**（与 §7.1、S5「排名发布后无法修改」一致）。
- 系统登录异常、页面报错、**志愿提交失败** → 截图 + 学号 + 操作步骤交辅导员，由学院汇总报智慧学工技术支持。
- 手册原文兜底：「手册内容如有与实际系统界面不一致之处，以系统页面显示为准」。

**产品话术三条（差距报告 / 兜底答案直接用）**：
1. 「综测分数出来 → 先看自己符合哪些奖项（系统自动判定）→ 按意愿排序 → 决定是否服从调剂 → 提交，提交后不能改」。
2. 「综合类只能拿一个，单项类可以拿多个但和综合类不能同时拿；单项建议全勾」。
3. 涉及"我能不能拿到 XX 奖"的预测 → **不预测**，只给资格条件与差距，评选结果以学院公示为准。

## 8. 国奖审批表填写口径（F6 样表 + F7 填写说明 2026 版）

判定门槛的三条硬规则，产品必须能答、且不能算错：
1. **成绩排名或综合考评排名必须位于前 10%**；证明材料须经学校审核盖章确认（F7 第 4 条）。
2. **比例不得四舍五入**：99 人中排第 10 = 10.1% → **按超出 10% 处理**（F7 第 4 条原文举例）。→ 规则卡/计算器遇到"卡线"必须按实际百分比判，不可美化。
3. 学习成绩为**年级同一专业第 1 名但该专业总人数少于 10 人**时，须提供**经学院审核盖章**的情况说明（F7 第 5 条）。
4. 排名范围由学校自定（院系/年级/专业/班级皆可），但**必须注明评选范围的总人数**，且同一学院、同一年级、同一专业的总人数应当一致（F7 第 3 条）。

**表格与文字硬要求（F7）**：两页、**不得增删页或改样式**、纸质原件**双面打印**；「基本情况」「申请理由」由**学生本人**填，其余各栏必须由**学校有关部门**填；字体统一**宋体小四**；重点核对**身份证号、手机号完整性**与政治面貌表述（群众/共青团员/中共党员）准确。
- **申请理由** ≈200 字，按「本人思想上、学习上、生活上……」写，书面化、**不能用「我」**、无错别字语病；开头结尾**不得**出现「尊敬的××」「您好！」「请批准」「谢谢」「此致敬礼」「恳请通过」。
- **推荐理由** ≈100 字，**推荐人必须是申请学生的辅导员**（表样栏位写"辅导员或班主任"）；开头写「张三同学……」，**必须写「推荐其获评国家奖学金」，不能写「推荐其申请国家奖学金」**；不得雷同/网上复制，**雷同率过高检测不通过、无法上报国家奖学金系统**。
- **日期链条**：辅导员推荐日期须晚于学生申请日期、早于学校公示日期；退回修改后重填的日期应为实际填表日期。
- **院（系）意见** ≈80 字，不得只写「同意」「同意推荐」，需学生工作负责人签字 + 学院公章；**不得由他人代写推荐意见或签名**。
- **诚信提醒（F4 操作手册原文）**：「请如实申报，不伪造、变造证明材料。弄虚作假一经查实，将按学校相关规定处理，并取消当学年评优评先资格。」→ 与 S1 第三十条（取消当年评奖评优资格并给予纪律处分）一致，可用于应答。
- **推荐理由、院（系）意见、学校意见的填写日期不得处于节假日**，落在节假日须提供学校盖章的情况说明（F7 第 10 条）。
- 「主要获奖情况」奖项名称要写全、颁奖单位表述正确，**同一奖项不得重复填写**（F7 第 6 条）。
- **「主要获奖情况」的填法（F6 样表红字批注）**：填上一年度学习、科研、文体、社会实践等的**院级及以上**主要荣誉，**只填最重要的四项**；**不填「四六级」「计算机等级」等技能证书**；颁奖单位以**证书公章**为准；按时间**由远及近**排列；**去掉学院前缀**（"公管学院-全国高校模拟集体协商（谈判）大赛二等奖" → "全国高校模拟集体协商（谈判）大赛二等奖"）；**去掉荣誉称号后缀**（"优秀志愿者团学先进个人" → "优秀志愿者"）；博文、大创等科研项目写「项目结项（第几作者）」。
- **一致性校验（F6 样表批注）**：申请理由不得罗列数字（如"均分 97.16（1/121）GPA 3.96"需重填）；须与基本情况/学习情况/获奖情况一致（政治面貌填群众就不能写"作为一名中共党员"；排名填第二名就不能写"专业成绩第一"）；申请理由与推荐理由提到的重大奖项，在「主要获奖情况」栏必须体现；政治理论学习内容须与时俱进。

**国奖表「学习情况」栏（F6 样表）**：含「成绩排名 / 总人数」「**实行综合考评排名：是**」「必修课 __ 门，其中及格以上 __ 门」「如是，排名 __ / __」。→ 与一票否决第 4 条（上学年所修读课程有不及格）直接相关：**必修课有不及格就报不了国奖**，这一栏是留痕点。

## 9. 文澜奖学金材料要求（F5 审批表，本学年权威）

审批表结构：基本情况（姓名/性别/出生年月/民族/政治面貌/入学时间/学号/联系电话/学院专业班/**曾获何种奖励**）→ 学习情况（**年级专业加权平均成绩排名 __ / __**、**年级专业综合评价得分排名 __ / __**）→ 典型个人事迹 → 申请人签名 → 辅导员意见 → 学院审核意见（签章）→ 学校审核意见（签章）。

- **获奖情况**：填大学期间已获重要奖项与荣誉，**必须写奖项全称 + 主办单位全称 + 获奖时间**；按**奖学金、竞赛、荣誉称号**顺序列；**同类奖项只取级别最高者**。
- **优秀事迹材料**：正文含标题与内容，**约 1000 字**；标题简练精确；内容要"有血有肉的故事性叙述"，**避免把思想品德、学习成果、实践创新、感恩回报几方面罗列成文**。
- **硬性支撑**：材料中提及的奖项**须提供获奖证明材料（复印件）**，**无证明材料不予认可**，随审批表一同报送。

## 11. 待核实清单（产品兜底话术的触发点）

1. 若学生所在学院本学年另行发文（目前仅统计与数学学院已取得），以学院文件为准；未取得的**不猜测**，必要时请学生向辅导员索取，而不是默认“各学院都不同”。

7. **中韩新媒体学院国奖 22 / 国励 5** 的结构异常（F3 sheet1）——文件夹内无任何说明，属未解异常，**不得自行解释成因**。

## 12. 比赛定级器（`--judge`，v3.1）

### 12.1 它做什么、不做什么

输入一句比赛描述（如“数学建模 省二等奖”“挑战杯校赛金奖”“美赛 M 奖”），输出：

1. 赛事全称与命中的别名；
2. 级别（国家级/省级/校级/院级）及判定依据；
3. 奖项档位与校发加分；
4. 集体项目折算；
5. 统数口径的差异（降等/不降/需核对）；
6. 置信度（高/中/低）。

**它只做“按规则取值”，不做“资格认定”。** 等级最终以证书落款（颁奖）单位为准（附表说明 7）；赛事是否被学校认可、材料是否有效，仍由学院/学校审核。

### 12.2 判定顺序（每一步都可追溯）

| 步骤 | 依据 | 说明 |
|---|---|---|
| ① 认赛事 | `赛事定级库.csv`（214 条） | 196 条分值映射 + 高频别名，同一赛事的不同写法已合并；**最长别名优先**，避免“挑战杯”吃掉“挑战杯创业” |
| ② 认级别 | 显式级别词 → 主办单位 → 赛事库级别提示 | 先剥离赛事名，避免“全国大学生数学建模竞赛”里的“全国”被误当级别 |
| ③ 认奖项 | 名次 → 特等/一/二/三等/金银铜 → 优秀奖 → 美赛字母 | 附表说明 5：不分等级按三等奖；名次按 1 / 2-3 / 4-6 / 7+ 折档；"国二""省二"等缩写按同档识别 |
| ④ 取分 | 分值表 + 集体折算 | 体育按名次取 1-8 档；学术科研按申报排序；文艺/体育的集体项目（n≥2）不论人数一律减半，个人项目不减半 |
| ⑤ 统数 | T2 降等表 | 白名单不降；美赛按字母；其余按“国→校、省→院”或降一级 |

### 12.3 什么时候**拒绝给分**

以下情形一律输出“暂不给分 + 需要补充什么”，不猜：

- 描述没有级别词、没有主办单位、赛事库也没有级别提示；
- 赛事未收录且描述无法判断级别（如“某校友企业杯 一等奖”）；
- 分值表没有对应的“子类 / 级别”组合。

### 12.5 已知限制

1. 赛事库对冷门赛事覆盖不全，未收录时会退化为“关键词归类 + 级别解析”，置信度标为中/低；
2. 同名赛事在不同年份的级别可能变化（如某赛新增省赛），以当年通知与证书落款为准；
3. 统数降等只覆盖 T2 明文列出的赛事；未列出的标为“需核对《推免奖励分细则》”，不擅自升降。
